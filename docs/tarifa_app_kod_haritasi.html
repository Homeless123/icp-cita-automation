1 · What are we building? / ¿Qué construimos?

🇬🇧 EN: A bilingual (ES/EN) web tool where a user enters their CUPS, a 3-month bill (photo or simple form) and optionally annual kWh + P1/P2/P3 split. The app collects live prices from all active Spanish electricity retailers, computes the real annual cost for that exact profile, shows HTML charts + plain explanations, and recommends which tariff makes sense — contacting companies by email only (no phones anywhere).
🇪🇸 ES: Herramienta web bilingüe (ES/EN) donde el usuario introduce su CUPS, una factura de 3 meses (foto o formulario simple) y opcionalmente consumo anual + reparto P1/P2/P3. La app recoge precios en vivo de todas las comercializadoras españolas, calcula el coste anual real para ese perfil, muestra gráficos HTML + explicaciones claras, y recomienda qué tarifa tiene sentido — contactando con las compañías solo por email (sin teléfonos).
Golden rules baked into the product / Reglas de oro del producto: ① Email only — the data model has no phone field. ② The app never signs contracts ("Contratar" buttons are never automated). ③ Every recommendation shows its math. ④ Indexed tariffs get scenario warnings. ⑤ SVA/insurance bundles are flagged and excluded by default.

Annualization rule / Regla de anualización: 3-month bill × 4 is naive. Better: weight by season (winter Q1/Q4 heavier for DH homes) using OMIE demand profiles, and always show a confidence band ("~1.180 – 1.320 €/y"). If the user supplies annual kWh, prefer it. If a DH bill gives P1/P2/P3, use it; else apply 2.0TD reference split (≈ 24% / 24% / 52%).

5 · Calculator engine / Motor de cálculo

# engine/calculator.py — core formula (all prices "sin impuestos")
from dataclasses import dataclass

VAT, IEE = 0.21, 0.0511269632          # configurable! (RDL changes tax rules)
TAX_FACTOR = (1 + IEE) * (1 + VAT)      # ≈ 1.27186 today

def annual_cost(tariff, profile, days=365):
    energy = sum(
        profile.kwh[p] * tariff.energy[p]      # p in {P1, P2, P3}
        for p in ("P1", "P2", "P3")
    )
    power = sum(
        profile.kw[p] * days * tariff.power[p]  # €/kW·día × kW × days
        for p in ("P1", "P2")
    )
    regulated = tariff.contador + tariff.bono_social_line   # small fixed lines
    return round((energy + power + regulated) * TAX_FACTOR, 2)

6 · Recommendation logic ("¿Cuál tiene sentido?")

# engine/recommender.py — the rules we validated in the field
RULES = {
  "min_savings": 100,            # €/year to justify switching
  "pool_indexed_max": 80,      # €/MWh: above this, never recommend indexed
  "exclude_sva": True,          # flag Servigas/seguro/maintenance bundles
  "promo_expiry_warn_days": 30,# warn when offer vigencia ends
}

def recommend(results, current):
    keep_current = True
    for r in sorted(results, key=lambda x: x.total):
        if r.sva_bundle:        r.verdict = "EXCLUDED — service bundle"
        elif r.indexed and pool_30d > RULES["pool_indexed_max"]:
            r.verdict = "RISK — pool too high right now"
        elif current.total - r.total > RULES["min_savings"]:
            r.verdict = "SWITCH CANDIDATE"; keep_current = False
    if keep_current:
        suggest "baja y volver" check with current retailer first
Plus / Además: a "before you switch" checklist is always printed: ① get the offer in writing ② ask your current retailer to match (retención) ③ never cancel before the new contract is confirmed — in Spain the switch is seamless ④ 14-day withdrawal right always exists.

  • price_history is append-only — the moment a company changes a price, we can prove it (this is how we caught Naturgy's two price sets and TE's 4.000 kWh trap).
  • tier_rule column exists because of TE: prices conditional on consumption must be modelled, not flattened.

9 · UI — bilingual HTML with charts / Interfaz bilingüe

Page flow / Flujo de páginas

  • 1. Home — language toggle ES/EN · "Compara tu factura / Compare your bill"
  • 2. Profile form — CUPS + bill upload/form + potencia (OCR prefills)
  • 3. Results — Chart.js bar (ranking €/y) · doughnut (P1/P2/P3) · scenario line for indexed
  • 4. Detail card per tariff: math shown line by line, flags, source link
  • 5. Verdict panel — plain language + "before you switch" checklist
  • 6. Email desk — pick companies → pre-filled ES/EN inquiry → review → send
  • 7. Export — self-contained HTML report (like our özet files) + email to self
